# Agent Foundry 文档站 Spec Kit 提示词

根据根目录 a.md 和以下讨论结论，为 apps/docs 起草 Agent Foundry 文档站规格。先读取 AGENTS.md、.specify/memory/constitution.md 和现有站点。按仓库约定设置 SPECIFY_FEATURE_DIRECTORY，将规格归入 specs/docs/NNN-<功能名>/，保留原始输入和讨论依据。本次交付 spec.md 及适用的规格检查结果。

本期目标是搭出可浏览、可扩展的文档站框架，采用 Nuxt UI。五个模块使用四套布局。

- home 承载首页。首页是以项目 AI 相关包为主题的全屏杂志式页面流。先用 Skills 和 MCP 作为可替换的章节示例，每章显示包名、占位正文和独立的 Three.js 模型。正式章节清单和文案后续补齐。
- skill 承载技能集合页和技能详情页。左侧是两级文件夹目录，一级是集合，二级是技能。集合页预留说明区域。技能详情页可直达，标题显示技能名称，正文先用占位。
- work-with-speckit 承载与 Spec Kit 协作。交付可点击、可切换选中项的一级左侧导航。栏目名称及正文均使用可替换的占位内容，正式目录后续确定。
- empty 供 MCP 文档和项目开发文档共用。两个模块分别有可直达的占位页，MCP 使用现有 /mcp 路由。

全局顶部提供技能文档、MCP 文档、与 Spec Kit 协作、项目开发文档四个一级入口。仅技能文档有集合子菜单，集合与左侧目录一致。品牌入口回首页。本期可用一份可替换的集合和技能样例数据验收导航。

Skill 包后续提供产物。dist/core 对应现有构建产物，新增 dist/docs 作为集合说明来源。集合文档字段省略或为 true 时读取默认 README，为字符串时读取集合目录中的指定文件，为 false 时跳过读取。找不到文件时告警并跳过该文档，继续处理其他集合。本站规格记录内容接入点，真实产物接入随 Skill 包就绪后验收。

使用可独立验证的用户故事和 Given/When/Then 场景，覆盖首页章节、全局菜单、两级技能目录、技能名称与占位正文、Spec Kit 占位栏目切换、移动端导航和路由直达。核对现有有效链接、无效地址的 404，以及 3D 加载失败时文档入口的可达性。将 Nuxt UI 集成、Three.js 渲染和 dist/docs 跨包接入列为后续 Plan 的技术验证项。当前工作止于需求规格。
