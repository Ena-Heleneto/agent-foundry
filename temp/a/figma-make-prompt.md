# Agent Foundry 文档站 Figma Make 提示词

为 Agent Foundry 创建一个简体中文技术文档站的可点击原型，覆盖桌面和手机。本期评审文档站框架，包括首页的全屏 3D 章节、全局导航和不同模块的布局。正式站点使用 Nuxt UI，原型中的菜单、按钮和目录状态应便于用 Nuxt UI 复现。

全站共享顶部导航，点击 Agent Foundry 品牌返回首页。一级菜单有「技能文档」「MCP 文档」「与 Spec Kit 协作」「项目开发文档」。仅技能文档有二级菜单，列出技能集合并链接到对应的集合页。手机端将菜单收进可展开的面板。

展示四套布局。

1. 首页是纵向翻阅的全屏杂志，以项目中与 AI 相关的包为主题。先用 Skills 和 MCP 做示例。每章占一屏，显示包名、简短占位正文和一个独立的 3D 模型。Skills 可以用立体文件夹，MCP 可以用连接节点。正式站点使用 Three.js，原型用轻量几何体演示，在实时渲染受限时显示对应的静态预览。
2. 技能文档左侧是两级文件夹树，一级为集合，二级为技能。用 frontend 和 workflow 演示集合进入、展开折叠和当前项高亮。从顶部子菜单和左侧目录进入同一个集合页。点开技能后，页标题显示技能名称，正文显示「文档待补充」。手机端可以打开和收起左侧目录。
3. 与 Spec Kit 协作使用常规的一级左侧导航。先用「栏目 A」「栏目 B」作为占位。点击后切换选中项，主区显示对应的占位标题和正文。
4. MCP 文档和项目开发文档共用简洁的布局，各自有独立页面，显示模块标题和占位说明。

首页用大标题和留白体现杂志感，内页以清晰的阅读层级为主。原型应能演示从首页进入技能集合、点开一个技能、切换其他文档模块，再通过品牌入口返回首页。
