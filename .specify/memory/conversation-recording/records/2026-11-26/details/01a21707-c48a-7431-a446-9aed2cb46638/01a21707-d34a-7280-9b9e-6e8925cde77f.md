# 业务节点实施顺序

在原任务内完成当前局部结果，核对真实前置后推进依赖它的步骤。节点是推进范围，沿用项目原任务与证据，不另建节点身份、编号、checkbox 或状态。

业务目标已明确、尚无正式任务时也可加载本技能，用于规划当前节点的实施路径；加载后仍核对目标项目及当前模式要求的材料与授权，缺少实施前置时只做允许的规划或核查，不自动补建正式任务或进入实现。

1. 读取目标项目有效规范、原目标/任务、当前节点、相关实现、依赖与实际证据，核对本次是规划还是已授权实施。Spec Kit 项目沿用其有效材料；其他项目沿用已有目标、任务和记录布局，不要求创建 `.specify`、MVU 或 Task ID。缺少必要目标、前置或授权时说明具体影响，仅暂停依赖它的操作；可继续已授权的无关工作。
2. 在原任务步骤中给出当前节点的预期结果、改动范围、适用顺序和可观察验收。默认展开当前节点适用的“数据设计/实现 → 后端业务或接口 → 验证逻辑 → 前端页面”。实际核对并复用已有成果与适用证据；无数据/后端职责时说明不适用层。需要调序时写明可核验的依赖与理由，例如先观察只读原型的文案布局；标明原型验证范围和仍缺的正式业务验收。
3. 在有效前置上仅实施已授权的当前范围。一个节点可只是一条接口，不必先补完整个 MVU 或所有业务后端，也不必为每条接口制作页面。页面依赖多个接口时，分别完成并验证接口，再汇合接入；正式页面接入后仍按其职责验证实际交互和所属业务结果。
4. 按职责和风险选择自动测试、实际接口请求、必要的临时页面或其组合，沿用项目必需检查。记录具体输入、预期和实际结果，覆盖正常及适用异常、权限边界；编译或路径存在不能代替业务验证。失败、未执行、证据不足分别如实保留，不计通过；仅阻止受影响下游，修复后实际复验再续接，无关且已授权工作可继续。

#!/usr/bin/env bash

set -e

# Parse command line arguments
JSON_MODE=false

for arg in "$@"; do
    case "$arg" in
        --json)
            JSON_MODE=true
            ;;
        --help|-h)
            echo "Usage: $0 [--json]"
            echo "  --json    Output results in JSON format"
            echo "  --help    Show this help message"
            exit 0
            ;;
        *)
            echo "ERROR: Unknown option '$arg'" >&2
            exit 1
            ;;
    esac
done

# Get script directory and load common functions
SCRIPT_DIR="$(CDPATH="" cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$SCRIPT_DIR/common.sh"

# Get all paths and variables from common functions
_paths_output=$(get_feature_paths) || { echo "ERROR: Failed to resolve feature paths" >&2; exit 1; }
eval "$_paths_output"
unset _paths_output

# Ensure the feature directory exists
mkdir -p "$FEATURE_DIR"

# Copy plan template if plan doesn't already exist
if [[ -f "$IMPL_PLAN" ]]; then
    if $JSON_MODE; then
        echo "Plan already exists at $IMPL_PLAN, skipping template copy" >&2
    else
        echo "Plan already exists at $IMPL_PLAN, skipping template copy"
    fi
else
    template_file=$(mktemp)
    trap 'rm -f "$template_file"' EXIT
    if resolve_template_content "plan-template" "$REPO_ROOT" > "$template_file"; then
        if [[ ! -s "$template_file" ]]; then
            echo "ERROR: Plan template is empty; no new plan.md was created." >&2
            echo "Restore a valid plan template and rerun plan setup." >&2
            exit 1
        fi
        cat "$template_file" > "$IMPL_PLAN"
        if $JSON_MODE; then
            echo "Copied plan template to $IMPL_PLAN" >&2
        else
            echo "Copied plan template to $IMPL_PLAN"
        fi
    else
        resolve_status=$?
        if [ "$resolve_status" -ne 1 ]; then
            exit "$resolve_status"
        fi
        echo "ERROR: Plan template not found; no new plan.md was created." >&2
        echo "Restore a valid plan template and rerun plan setup." >&2
        exit 1
    fi
fi

# Output results
if $JSON_MODE; then
    if has_jq; then
        jq -cn \
            --arg feature_spec "$FEATURE_SPEC" \
            --arg impl_plan "$IMPL_PLAN" \
            --arg feature_dir "$FEATURE_DIR" \
            --arg branch "$CURRENT_BRANCH" \
            '{FEATURE_SPEC:$feature_spec,IMPL_PLAN:$impl_plan,FEATURE_DIR:$feature_dir,BRANCH:$branch}'
    else
        printf '{"FEATURE_SPEC":"%s","IMPL_PLAN":"%s","FEATURE_DIR":"%s","BRANCH":"%s"}\n' \
            "$(json_escape "$FEATURE_SPEC")" "$(json_escape "$IMPL_PLAN")" "$(json_escape "$FEATURE_DIR")" "$(json_escape "$CURRENT_BRANCH")"
    fi
else
    echo "FEATURE_SPEC: $FEATURE_SPEC"
    echo "IMPL_PLAN: $IMPL_PLAN"
    echo "FEATURE_DIR: $FEATURE_DIR"
    echo "BRANCH: $CURRENT_BRANCH"
fi
