# Verification Before Completion

## Overview

**Core principle:** Evidence before claims, always.

**Violating the letter of this rule is violating the spirit of this rule.**

## The Iron Law

```
NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE
```

If you haven't run the verification command in this message, you cannot claim it passes.

## The Gate Function

```
BEFORE claiming any status or expressing satisfaction:

1. IDENTIFY: What command proves this claim?
2. RUN: Execute the FULL command (fresh, complete)
3. READ: Full output, check exit code, count failures
4. VERIFY: Does output confirm the claim?
   - If NO: State actual status with evidence
   - If YES: State claim WITH evidence
5. ONLY THEN: Make the claim

Skip any step = lying, not verifying
```

## Common Failures

| Claim | Requires | Not Sufficient |
|-------|----------|----------------|
| Tests pass | Test command output: 0 failures | Previous run, "should pass" |
| Linter clean | Linter output: 0 errors | Partial check, extrapolation |
| Build succeeds | Build command: exit 0 | Linter passing, logs look good |
| Bug fixed | Test original symptom: passes | Code changed, assumed fixed |
| Regression test works | Red-green cycle verified | Test passes once |
| Agent completed | VCS diff shows changes | Agent reports "success" |
| Requirements met | Line-by-line checklist | Tests passing |

## Red Flags - STOP

- Using "should", "probably", "seems to"
- Expressing satisfaction before verification ("Great!", "Perfect!", "Done!", etc.)
- About to commit/push/PR without verification
- Trusting agent success reports
- Relying on partial verification
- Thinking "just this once"
- Tired and wanting work over
- **ANY wording implying success without having run verification**

## Rationalization Prevention

| Excuse | Reality |
|--------|---------|
| "Should work now" | RUN the verification |
| "I'm confident" | Confidence ≠ evidence |
| "Just this once" | No exceptions |
| "Linter passed" | Linter ≠ compiler |
| "Agent said success" | Verify independently |
| "I'm tired" | Exhaustion ≠ excuse |
| "Partial check is enough" | Partial proves nothing |
| "Different words so rule doesn't apply" | Spirit over letter |

## Key Patterns

**Tests:**
```
✅ [Run test command] [See: 34/34 pass] "All tests pass"
❌ "Should pass now" / "Looks correct"
```

**Regression tests (TDD Red-Green):**
```
✅ Write → Run (pass) → Revert fix → Run (MUST FAIL) → Restore → Run (pass)
❌ "I've written a regression test" (without red-green verification)
```

**Build:**
```
✅ [Run build] [See: exit 0] "Build passes"
❌ "Linter passed" (linter doesn't check compilation)
```

**Requirements:**
```
✅ Re-read plan → Create checklist → Verify each → Report gaps or completion
❌ "Tests pass, phase complete"
```

**Agent delegation:**
```
✅ Agent reports success → Check VCS diff → Verify changes → Report actual state
❌ Trust agent report
```

## When To Apply

**ALWAYS before:**
- ANY variation of success/completion claims
- ANY expression of satisfaction
- ANY positive statement about work state
- Committing, PR creation, task completion
- Moving to next task
- Delegating to agents

**Rule applies to:**
- Exact phrases
- Paraphrases and synonyms
- Implications of success
- ANY communication suggesting completion/correctness

"""Codex 的 UserPromptSubmit 命令入口，负责保存并读回用户消息。"""

from pathlib import Path
import sys

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

from recording.events import collect, redacted
from recording.record import open_turn, run_hook, session_lock
from recording.subagents import recover_subagent_messages


def record_prompt(scope, data):
    """在业务开始前保存并读回用户发起的消息或同轮补充。"""
    prompt = data.get("prompt")
    if not isinstance(prompt, str):
        return
    prompt = redacted(prompt)

    with session_lock(scope):
        turn = open_turn(scope)
        if not turn.messages:
            turn.append("发起", prompt)
            document = turn.save(scope)
            recover_subagent_messages(scope, turn.path, document)
            return

        count = sum(label in {"发起", "补充"} for label, _ in turn.messages)
        repeated = turn.messages[-1] in (("发起", prompt), ("补充", prompt))
        # 用宿主输入条数区分重复回调和真实的同文补充。
        if not repeated or len(collect(scope).inputs) >= count:
            turn.append("补充", prompt)
            turn.save(scope)


if __name__ == "__main__":
    run_hook("UserPromptSubmit", record_prompt)

RESUME_PROMPT = "请只回复 T040_RESUMED。"

def observe(kind, **values):
    row = {"kind": kind, "ns": time.monotonic_ns(), **values}
    with TRACE.open("a", encoding="utf-8") as output:
        output.write(json.dumps(row, ensure_ascii=False, separators=(",", ":")) + "\n")


def rows(path=TRACE):
    if not path.is_file():
        return []
    return [json.loads(line) for line in path.read_bytes().splitlines(keepends=True) if line.endswith(b"\n")]


def formal(label, value):
    heading = "用户 · 发起" if label == "发起" else "主代理 · 回复"
    return f"<!-- foundry-message {label} {len(value)} -->\n\n### {heading}\n\n{value}\n"


def record_for(session):
    for path in REPO.glob("records/*/*/record.md"):
        if re.search(rf"^会话 `{session}`", path.read_text(), re.M):
            return path
    return None


def add_naming_instruction():
    """先执行正式安装脚本，读回原话后才追加派发指令。"""
    contents = sys.stdin.buffer.read()
    data = json.loads(contents)
    installed = REPO / ".agents/skills/conversation-recording/scripts/user_prompt_submit.py"
    previous = subprocess.run([sys.executable, "-B", str(installed)], input=contents, cwd=REPO, capture_output=True)
    if previous.returncode or previous.stdout or data.get("prompt") != PROMPT:
        observe("RecorderDiagnostic", returncode=previous.returncode, producedOutput=bool(previous.stdout))
        sys.stdout.buffer.write(previous.stdout)
        raise SystemExit(previous.returncode)
    record = record_for(data["session_id"])
    assert record and formal("发起", PROMPT) in record.read_text(encoding="utf-8")
    gate = shlex.join([sys.executable, "-B", __file__, "--await-release"])
    delegated = (f"{MARKER}。你是本会话的命名子代理。以下是用户已落盘的原话：{PROMPT}\n"
                 "先执行这个只读命令来等待隔离探针放行："
                 f"{gate}\n命令结束后，按原话中的彩虹问题判断主题，输出 JSON 对象，只含 title 字段。"
                 "主题明确就填一个简短中文标题，主题不明确就填 null。")
    hint = ("【项目的会话记录命名工作流】本轮用户原话已保存。请先调用 Codex 原生子代理工具，"
            "创建一个名为 recording_title 的命名子代理，把下面的完整任务文本作为 message 传给它。"
            "若工具支持 fork_context，请设为 false。创建后直接正常回答用户的问题。"
            "不等待、不查询命名子代理的结果，主回复只回答原问题。\n\n" + delegated)
    observe("OriginalSavedBeforeHint", session=data["session_id"], turn=data["turn_id"], prompt=PROMPT,
            record=record.relative_to(REPO).as_posix(), savedSha256=sha256(record.read_bytes()).hexdigest(),
            additionalContextSha256=sha256(hint.encode()).hexdigest())
    print(json.dumps({"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": hint}},
                     ensure_ascii=False))


def observe_hook(event):
    """只保留本次合成运行的必要字段。"""
    data = json.load(sys.stdin)
    values = {key: data[key] for key in ("session_id", "turn_id", "agent_id", "agent_type", "tool_use_id",
                                         "tool_name", "last_assistant_message", "model", "stop_hook_active")
              if key in data}
    if event == "PostToolUse":
        values["probeMarkerInInput"] = MARKER in json.dumps(data.get("tool_input"), ensure_ascii=False)
    if event == "SubagentStop" and data.get("agent_transcript_path"):
        values["agentLogName"] = Path(data["agent_transcript_path"]).name
    observe(event, **values)
    print("{}")


def await_release():
    """从子代理工具等待主回复读回。"""
    deadline = time.monotonic() + 85
    while time.monotonic() < deadline:
        if RELEASE.is_file():
            print("FOUNDRY_TITLE_GATE_OPEN")
            return
        time.sleep(0.07)
    raise SystemExit("命名结果等待超时")


def git(*arguments):
    subprocess.run(["git", *arguments], cwd=REPO, check=True, capture_output=True)


def mux(*arguments):
    return subprocess.check_output(["tmux", "-f", str(WORK / "tmux.conf"), "-S", str(WORK / "terminal.sock"), *arguments],
                                   stderr=subprocess.STDOUT, text=True)


def screen():
    try:
        return mux("capture-pane", "-p", "-S", "-110", "-t", SESSION)
    except subprocess.CalledProcessError as error:
        return error.output


def wait(predicate, label, timeout=30):
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        result = predicate()
        if result:
            return result
        time.sleep(0.075)
    raise TimeoutError(label)


def start(arguments=(), zone=None):
    command = ("env", f"TZ={zone}", str(BINARY)) if zone else (str(BINARY),)
    mux("new-session", "-d", "-s", SESSION, "-x", "114", "-y", "32", "-c", str(REPO),
        *command, "--no-daemon", "--no-alt-screen", *arguments)

def finals(session):
    selected = []
    for row in log_for(session):
        payload = row.get("payload", {})
        if (row["type"] == "response_item" and payload.get("type") == "message"
                and payload.get("role") == "assistant" and payload.get("phase") == "final_answer"):
            body = "".join(part["text"] for part in payload["content"] if part["type"] == "output_text")
            selected.append({"timestamp": row["timestamp"], "body": body})
    return selected


def hook_row(event, session):
    return next((row for row in rows() if row["kind"] == event and row.get("session_id") == session), None)


def run(reuse=False):
    if not reuse:
        REPO.mkdir()
        git("init", "-q")
        (REPO / "README.md").write_text("命名派发隔离样例。\n", encoding="utf-8")
        git("add", "README.md")
        git("-c", "user.name=Foundry Fixture", "-c", "user.email=fixture@example.invalid",
            "commit", "-qm", "fixture baseline")

        maintained = WORK / "source"
        subprocess.run([sys.executable, "-B", str(maintained / "install.py"), "--project", REPO],
                       cwd=REPO, check=True, capture_output=True)
        installed = REPO / ".agents/skills/conversation-recording"
        checked = {p.relative_to(maintained).as_posix(): sha256(p.read_bytes()).hexdigest()
                   for p in maintained.rglob("*") if p.is_file()}
        assert all(sha256((installed / name).read_bytes()).hexdigest() == expected for name, expected in checked.items())
        observe("Install", cli=subprocess.check_output([BINARY, "--version"], text=True).strip(),
                installedFiles=len(checked), sourceHashes=checked)
        hook_file = REPO / ".codex/hooks.json"
        config = json.loads(hook_file.read_text())
        assert set(config["hooks"]) == {"UserPromptSubmit", "PostToolUse", "SubagentStop", "Stop"}
        config["hooks"]["UserPromptSubmit"][0]["hooks"][0]["command"] = shlex.join(
            [sys.executable, "-B", __file__, "--submit"])
        for event in EVENTS:
            command = shlex.join([sys.executable, "-B", __file__, "--observe", event])
            config["hooks"].setdefault(event, []).append({"hooks": [{"type": "command", "command": command}]})
        hook_file.write_text(json.dumps(config, indent=2) + "\n", encoding="utf-8")

        (STATE / "config.toml").write_text(
            'model = "gpt-6.2-sol"\nmodel_reasoning_effort = "medium"\n'
            'check_for_update_on_startup = false\napproval_policy = "never"\nsandbox_mode = "read-only"\n'
            'cli_auth_credentials_store = "file"\n[features]\nmulti_agent_v2 = true\n'
            'multi_agent_v2_dynamic_tools = false\n', encoding="utf-8")
    hook_file = REPO / ".codex/hooks.json"
    tools = runpy.run_path(str(WORK / "helpers/recording-hook-probe.py"))

    def discovered():
        return asyncio.run(tools["list_hooks"](str(BINARY), REPO, (REPO,)))[0]["hooks"]

    login = subprocess.run([BINARY, "login", "status"], capture_output=True, text=True)
    assert login.returncode == 0 and "ChatGPT" in login.stdout + login.stderr
    observe("NativeLogin", via="现有原生登录只读挂载")
    try:
        if not reuse:
            assert not discovered()
            start()
            wait(lambda: "Trust and continue" in screen(), "首次临时项目目录信任", timeout=60)
            time.sleep(0.32)
            mux("send-keys", "-t", SESSION, "Enter")
            wait(lambda: "Trust all and continue" in screen(), "首次 Hook 信任")
            untrusted = discovered()
            assert untrusted and all(entry["trustStatus"] == "untrusted" for entry in untrusted)
            mux("send-keys", "-t", SESSION, "Down")
            wait(lambda: "› 2. Trust all" in screen(), "选择临时 Hook 信任")
            mux("send-keys", "-t", SESSION, "Enter")
            wait(lambda: "gpt-6.2-sol medium" in screen().lower(),
                 "原生启动就绪", timeout=45)
            trusted = discovered()
            assert len(trusted) == len(untrusted)
            assert all(entry["trustStatus"] == "trusted" and entry["enabled"]
                       and Path(entry["sourcePath"]) == hook_file for entry in trusted)
            observe("NativeTrust", hooks=[entry["eventName"] for entry in trusted])
            end()

        else:
            entries = discovered()
            assert entries and all(entry["trustStatus"] == "trusted" and entry["enabled"]
                                   and Path(entry["sourcePath"]) == hook_file for entry in entries)
