# Codex CLI 会话归属与身份

开始自动记录前，先实际运行当前活跃轮次的只读核查并取得工具返回，再判定归属。工具目录位于仓库外时仍按此顺序核查。只有核实归属后才读取已有记录或会话正文，并将本轮交给保存流程。遇到非交互入口、仓库范围不符、证据缺失或冲突时，跳过自动记录及正文补读，直接继续用户任务。核验仅使用当前项目位置和当前线程的宿主元数据。

## 核对仓库与当前轮次

1. 从当前项目的启用范围取得目标仓库根。解析真实目录，并用 `git -C <项目根> rev-parse --show-toplevel` 比对该项目根。判断目录归属时先解析符号链接，再检查等于仓库根或是其实际下级目录。同名前缀的目录仍按各自的目录层级判定。
2. 在宿主现有命令工具中取得 `CODEX_THREAD_ID`，保留规范的 UUID。使用该 CLI 实际状态目录和唯一匹配此 UUID 的 `rollout-*-<UUID>.jsonl`。会话文件定位限于匹配名称。状态目录、标识或文件归属无法核实时结束自动记录核验。
3. 在 Linux 的 Codex CLI 0.171.0 前台分页布局中，以只读方式打开 `thread_history_1.sqlite`，按该线程查询 `thread_turns` 的 `turn_id`、`status` 和 `rollout_byte_offset`。要求恰有一条 `status=inProgress` 的轮次且有有效字节偏移。这一步同时取得该线程已索引的轮次计数。
4. 用宿主命令工具在匹配文件中按字节偏移定位。无缓冲核对事件类型为 `event_msg`、载荷类型为 `task_started` 后，只读取该行的元数据，核对事件的 `turn_id` 与活跃轮次一致，再取 `turn_attribution.turn_trigger`。头部类型不符时立即停止读取。遇到 `exec`、缺失或不支持的触发类型时结束自动记录核验。后续分支只处理已验证的 `user` 活跃轮次。
5. 若本次启动的临时值缺失，继续取得两项数据再判断归属：匹配线程文件起始处唯一一行 `session_meta` 的会话 ID、`source`、`originator` 及首次目录，以及用未指定工作目录的宿主命令工具运行 `pwd -P` 得到的有效工作目录。核对会话 ID 与当前线程相同、`source=cli`、`originator=codex-tui`，并解析这两个目录。两处均在目标仓库范围内即可进入对应保存分支。恢复前的启动路径可缺省。

## 决定本次是否记录

**首次交互。** 在活跃轮次为唯一已索引轮次时，核对本次活跃事件紧接在会话元数据之后。存在其他历史或派生来源的证据时，应按恢复条件核验。用匹配会话文件名的本地日期作为开启日，跨午夜发首条也沿用该日期。

**同一次启动的后续轮。** 通过当前 Code Mode 工具实际 `load("conversation-recording:launch:" + threadId)`。该临时值仅在本次启动核实归属后用同一工具 `store` 写入，包含 `threadId`、`repoRoot`、`originalCwd`、`openingDate` 和 `entryEvidence`。用本轮宿主返回的 `threadId` 与已核对的真实仓库根匹配凭据前两项。首次有效工作目录、开启日及起始入口证据从实际读回的凭据取得，本轮活跃事件只用于核对当前线程、轮次和触发类型。凭据中的首次目录仍须属于目标仓库。连续轮次沿用原始目录和日期。业务工具自己的工作目录只关联该工具活动。

**交互式恢复。** 本次启动的临时值缺失且有历史轮次时，按第 5 步实际取得原会话元数据及恢复后的有效工作目录。两处均属于目标仓库时，按原会话文件名中的本地日期定位记录并续写。当前项目安装的规则适用于曾按旧版跳过自动记录的同一会话。归属不符、证据缺失或冲突时跳过。核实范围后，将线程、仓库根、首次目录、开启日和本次入口证据按同一次启动的临时值规则保存，便于后续轮使用。

临时值以工具本轮真实返回为准。看到旧对话中的值或磁盘上的记录时，继续按本次入口核验。完成范围核验前只使用上述元数据，不遍历会话正文或读取记录文件。

## 随记录保存的身份

在成对索引、详情中保留同一组可核实的身份信息，包括宿主线程 UUID、规范化仓库根、首次有效工作目录、实际本地开启日，以及入口证据。入口证据保留宿主版本与事件来源、已核实的活跃轮次 ID、触发类型和实际用于核验归属的目录。恢复时保留原有会话身份，在本轮证据中标明恢复后的有效工作目录。同次启动的凭据仅表示范围已核实，文件保存仍以实际读回确认。

已验证 UUID 可用作文件基名。使用线程 UUID 与真实仓库根共同确认归属，按原开启日定位成对文件。复用前核对已存的线程、仓库根、首次工作目录与开启日。证据冲突时保留现有文件，停止对该会话的自动写入。满足恢复条件但尚未建档时，按原开启日定位，从恢复后的首条消息开始保存。[共用资料契约](storage-contract.md)

这些宿主字段已在 Linux 的 Codex CLI 0.171.0 前台分页会话取证。其他入口或历史布局需先取得适用的等价证据。
