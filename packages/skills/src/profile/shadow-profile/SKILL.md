# 影子画像

本技能独立运作，由主 AI 在每轮用当前可用的文件工具保存可见对话，读回确认后再摘要或分析。不依赖 Spec Kit、AGENTS/CLAUDE 路由、会话日志、宿主版本或常驻记录脚本。启用后每轮完整读取本正文；发现、加载、实际保存分别核验，未覆盖如实说明。

删除、移走、清空或归档已有记录只影响旧资料，不停用技能；后续对话正常记录，资料根缺失时沿原布局重新建立，从清理后的新对话开始，不从归档或仍可见的上下文回填已清除内容。只有用户明确要求暂停或停止后续记录时才停用，直到明确要求继续；安装、重启或自然匹配不能解除明确暂停，继续时不补录暂停期间发言。

## 定位与恢复

沿目标项目已有布局定位唯一资料根；无约定时用 docs/user-shadow/，不初始化 Spec Kit，不写入技能目录。多个冲突资料根先澄清，不自动迁移。新会话、恢复或依据变化时先读 profile.md，再核对必要来源；无资料时从当前可见内容开始，不导入其他项目私人资料。

## 每轮先保存原文

读取已有原文和覆盖说明，确定当前会话已经保存到哪里。用普通文件工具依次保存尚未记录的用户发言和已发出的助手发言，包括可见过程说明、上一轮真实最终回复。先落盘并读回核对正文、角色和顺序，再保存摘要、形成认识或交给分析者；写入返回成功还不能代替读回。

新原文默认放 conversations/raw/YYYY-MM-DD.md，每条用未占用且不复用的 Mnn 标题，保留会话/轮次来源、角色、顺序、实际可知日期及完整正文。正文使用足够长的代码围栏原样包裹，保留换行、空白、Markdown、中文和 emoji，不改写成摘要、不因入口篇幅预算截断。按项目现有等价原文布局保存也可以，旧 JSONL 和日期摘要不批量改写。

宿主会话或消息 ID 可见时使用真实值；不可得时用明确标注的本地会话定位、轮次关系及文件锚点，不伪造宿主 ID 或精确时间。去重依据来源关系及已存位置；同轮重入只补缺项，不同轮相同文字分别保留。无法确认是否同一条时记录身份缺口，不按文本相同合并。

工具参数/原始返回、思维、系统/开发者提示不进入原文；助手已发出的执行说明仍是对话。控件仅保留真实可见发言，非文本仅记可核验引用和必要说明，不复制原件。不可见或已压缩丢失的内容说明缺档，不从摘要或画像倒推原话。

当前尚未发送的 final 不算已发生；下一轮仍可见时再补存上一轮真实 final，注明补存。本轮覆盖截至最后一条已读回消息；没有后续调用或中断时不承诺末轮 final 已存，不预记成功、不退出后另起程序补录。

## 摘要、认识与入口

原文读回后，在 conversations/YYYY-MM-DD.md 延续未占用 Rnn 摘要，链接原文锚点，保存意图、决定及理由、纠正、实际工具目的与结果和覆盖缺口。同轮只补新增事实。

有新认识才在 conclusions/YYYY-MM-DD.md 延续 Enn，链接真实原文和摘要，区分明确表达、情境决定、暂定观察及他人/Agent建议。业务选择不自动成为永久偏好，人工演练不进入真实本人画像。更正保留旧来源并新增更正依据，注明旧认识的失效范围；冲突未明保留双方依据和待核实点。

新偏好、持续目标、用户纠正或手动分析要求可触发独立分析；分析者只读取已经落盘并读回的范围，普通对话先积累。宿主没有可用分析能力时如实说明，记录与正常协作继续，不冒认已派发或完成分析。

整体理解变化才更新 profile.md，正文最多2000字，认识链接结论及来源；无新认识不刷新。首次无有效认识时，原文和摘要保存后建立注明理解不足的入口，不强造结论。当前纠正立即用于协作，实际应用效果有机会才验。

## 覆盖与保存故障

沿项目既有记录注明已存原文、摘要、分析、入口各自范围及缺口；需要独立说明时用 conclusions/coverage.md，不另建状态服务。已有未知覆盖格式保留现场，不覆盖或删除以求通过。

每次写前重读，局部合并，同根串行保存，不以旧内存覆盖外部新改动。没有程序锁，不承诺任意并发无损；发现冲突保留双方依据，暂缓受影响汇总，正常答复继续。

获准保存且工具允许时实际尝试一次，以真实返回说明已写/未写和恢复入口；预检查不等于尝试，部分成功不报全部成功。原文未确认则停止依赖它的摘要/分析；成功部分保留，失败在下一次可见反馈说明。恢复只补仍可核实的缺项，不重复建档或捏造错误。

资料留在目标项目，当前仅维护使用者本人；不复制其他仓库画像、凭据或机器配置，不自动提交、推送或公开。
