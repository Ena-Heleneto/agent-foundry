## 当前提供什么

Agent Foundry维护技能正文、必要附件、分发脚本与Spec Kit扩展。技能用于让编码代理按约定工作；项目规范、当前授权及真实验收仍由目标项目维护。

两条工作线彼此独立：主线正在重写分发构建；紧急版面向Linux x86_64、Codex和项目级安装。选择安装方式前，请先阅读对应的支持范围。

## 当前交付边界

当前没有已经发布的公开安装来源。文档提供本地开发和已备来源的操作说明，不将示例当成现成下载地址。

Implement和Increment是当前工作流方向；Pair、Tutor、Direct不属于本期活动交付。MCP源码和测试已保留，旧清单契约仍需与主线构建对齐。
