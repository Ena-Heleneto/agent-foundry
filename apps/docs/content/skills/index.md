## 编码约定

| 技能                     | 使用时机                                                   |
| ------------------------ | ---------------------------------------------------------- |
| business-node-delivery   | 把业务目标落实为当前节点的实施顺序、依赖与验收             |
| document-changed-symbols | 编辑TS、JS、Vue时，为新增或语义修改的声明维护中文多行JSDoc |

## 前端开发

| 技能            | 使用时机                                                |
| --------------- | ------------------------------------------------------- |
| nuxt-ui-styling | Nuxt UI、UnoCSS与Tailwind的样式写法、属性冲突及生成检查 |
| vue-reactivity  | 使用声明式响应式数据流，默认不新增watcher               |

## 协作与交付

| 技能                         | 使用时机                                             |
| ---------------------------- | ---------------------------------------------------- |
| implementation-preparation   | 实施前核对材料、讨论当前任务方案、保存并读回认可依据 |
| task-increment               | 在已有方案中增量规划可验证业务单元和必要任务         |
| artifact-spec-analysis       | 从规格、方案、任务及实际证据生成逐功能说明和综合分析 |
| artifact-project-description | 验收后依据实际交付整理目标、范围、成果和遗留事项     |
| bug-report                   | 用户明确要求时整理可复现现象、关联材料和修复建议     |

## 来源与附件

九项技能的完整来源在packages/skills-distribution-urgent/src下的coding、frontend和workflow集合。references目录属于技能内容，不能只取SKILL.md而丢失必要附件。

主线同时保留临时来源和eval评估样本。主线eval选择配置仍有待对齐的实验状态；本页列出的九项正式技能不包含这些样本，也不将历史验收候选当成新技能。

主线 `packages/skills` 已移除 bug-report 的技能来源及挂载声明，workflow 当前保留四项技能。本页九项清单对应紧急版独立来源，不作为主线当前清单。
