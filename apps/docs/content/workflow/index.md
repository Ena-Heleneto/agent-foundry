## 使用前提

Spec Kit工作流消费目标项目已有的规格、方案、任务及有效治理。应先确认项目已初始化、所需CLI及正式材料存在；安装技能副本不会自动完成这些前置。

当前紧急版使用Specify CLI 1.2.6。挂载时还需要Bash、Git、jq等实际工具；版本及平台条件以包内README为准。

## 开始实施

implementation-preparation围绕已有原任务核对目标、当前证据和分工，讨论并保存本任务的实施方案。只有取得适用认可并满足真实前置，才进入具体代码实现。

任务、局部技术检查、业务验收和用户效果分别判断；不能因为方案文件存在、构建成功或代理读取了技能，就把原任务算作完成。

## 增量规划

Increment沿已有方案和实际需求变化补充可验证单元、依赖和必要任务，保留原身份与完成证据。它显式复用同一artifact-spec-analysis能力，不注册另一个after_increment事件。

## 分析与交付

所选hooks连接实施准备、任务后分析和适用的项目说明。具体选择、显式执行顺序、条件和失败处理由同版集合配置与注册脚本负责。

官方skills安装与同版公共脚本挂载是两个步骤。不要把安装后的文件存在当成hooks已经注册；也不要恢复旧材料中的Pair、Tutor、Direct活动入口。

## 项目自己的规则

通用技能沿目标项目现有工程规范、授权和记录布局工作，不要求复制本仓库的私人画像、会话或其他项目治理。
