# T020 实施方案

2026-11-27，T019 的四块试转画板通过验收。用户收到「下一步是 T020 的 165 项全量转换」后回复「开始吧」，确认本轮执行全量转换。使用试转的同一 Figma Design 文件。 [原任务](../tasks.md#phase-8-user-story-6---一次启动将原型页面和状态转换为可编辑画板priority-p2) · [试转结果](../analysis/figma-conversion.md#t019-代表性试转)

按已经实测的 15 个视图和导航组合生成 165 个独立采集项，桌面 84 项，手机 81 项。沿用 1440 × 900 和 390 × 844 视口。先以路径、期望可见内容和真实控件操作核对每项，再以一次启动的 Playwright 批次驱动 Figma 官方采集脚本。每次提交消费各自的采集编号，按服务返回的回执和后续编号推进。将回执逐项保存，以实际落图状态恢复失败项。 [实际原型清单](../analysis/figma-conversion.md#页面与视口) · [转换方式实测](../analysis/figma-conversion.md#t018-转换方式实测)

在同一 Design 文件中使用「T020 全量转换」页组织具名原生画板。沿用试转验证过的视口裁切、桌面顶栏内边距、首页原纹理平铺、Noto Serif SC 标题、已确认的 Noto Sans SC 中文无衬线替代和 Three.js 静帧处理。逐项核查画板唯一映射、正文与导航状态、原生文字与布局、字体布局和实际图像。将链接、差异和通过、失败或缺前置记录写入分析，达到原任务的 100% 条件后更新 T020。 [Design 文件](https://www.figma.com/design/xd4v3YLbHr6MFrshieoSPs/Untitled?node-id=0-1) · [验收契约](../contracts/site-navigation.md#页面转换契约figma)
