# 文档站

我需要一个文档站, ui库使用nuxt ui ,共包含5个模块
首页，skill文档 , mcp站文档 ，与speckit协作， 项目开发文档

## @apps/docs

- 新增layout/home 用来承载首页的页面流
- 假定每个模块的页面布局组件不一致，有模块对应的layout，
- 我们现在需要准备n个layout
  - home
  - skill
  - work with speckit
  - empty

## 首页

首页使用全屏杂志风格，使用 threejs构建3D效果，每个杂志页都有3D模型

## 模块

### skill

- 我们需要在修改skill的构建产物 dist/docs dist/core
- 集合的配置文件中新增一个文档字段，功能是指定集合的文档文件，默认为true，如果为true时，则读取集合目录下的 README ，如果为字符串，则读取对应文件名的文件，如果为false，则不读取
- 如果找不到配置中对应的文档文件，则控制台告警并跳过
- dist/docs 为新增的文档产物，来源则是 上面提到的文档
- 模块级组件
  - 模块内部导航
  - 二级导航，一级导航是集合名，二级是下面的skill
  - 在页面的左侧
  - 文件夹风格

### mcp站点

保留header菜单路由，但是内容使用占位内容，本期不做mcp

### work with speckit

- 除了导航组件，其他的内容使用占位内容
- 模块级组件
  - 页面的左侧
  - 一级目录
  - 一个常规的左侧导航

### 项目开发文档

- 使用占位内容

## 全局组件

- 顶部菜单
  - 包含一级和二级菜单
  - 一级菜单是 skill文档 , mcp站文档 ，与speckit协作， 项目开发文档 这四个模块
  - skill文档对应的二级菜单是skill 下的各个集合
