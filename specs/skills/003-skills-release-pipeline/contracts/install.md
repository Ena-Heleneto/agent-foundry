# 主线安装契约

## 固定入口与选择

入口为目标环境下载根的 install.sh，也以相同字节放在候选的 curl/install.sh。执行形式为 bash install.sh [version] [--no-mount] [--hidden]。保留当前项目级安装和引擎选项，默认安装到当前隔离或实际 Codex 项目的 .agents/skills。

入口从自身绑定的环境下载根获取 release.json，使用 HTTPS。默认及 latest 取数组第一条，显式标识按 version 字符串精确匹配唯一条目。索引结构无效、空表或版本未唯一匹配时提前报错。默认选中首条但不可用时报告该版本及失败步骤。生产或公开发布候选的下载根来自验证后的实际目标配置。

## 安装前置与结果

1. 读取并固定当次选中记录。校验 version、url、bytes 和 sha256 的格式，按该 URL 获取归档。下载及重定向均保持 HTTPS 与证书校验。 [索引字段](../data-model.md#版本表与准备快照)
2. 在独占临时目录内核对归档的字节长度和 SHA-256。按现有正式交付边界验证安全的归档成员，只在独占目录解包，并读取唯一普通 VERSION 文件。releaseTimestamp 必须等于选中条目的 version。
3. 三项检查及必要包结构通过后才进入项目安装。项目已有的同名内容沿用当前冲突保护。保留同包 engine/install.sh 与现行挂载、隐匿选项及退出语义，继续支持已有测试覆盖的包内旧隐匿路径。
4. 版本选择、URL、下载、摘要、长度或包内版本失败时，返回失败和明确原因，项目写入及后置脚本调用数为 0。部分技能安装和安装后挂载、隐匿失败继续按既有结果独立报告。
