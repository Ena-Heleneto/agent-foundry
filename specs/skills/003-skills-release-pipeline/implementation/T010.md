## 作业内步骤

准备作业依次下载候选和旧表、按需初始化、生成新表并保存制品。下载步骤交接 GET 退出码、下载文件和原始响应。退出码为零时直接进入生成步骤。失败时由初始化步骤确认 `NoSuchKey` 后写入空数组，其他错误在该步终止。生成步骤从同次响应读取已有表的 ETag，校验完成后保存新 `release.json` 和作业输出。

本地按实际 YAML 顺序执行独立 Bash 步骤，核对步骤依赖、制品路径和输出。10 项场景通过，覆盖已有历史和 ETag、两种明确缺失格式、权限与网络错误、重复标识及无效 JSON。 [独立作业](../../../../.github/workflows/skills-deploy-common.yml#L88)
