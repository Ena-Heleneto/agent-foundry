# T072：按集合自动发现与复制技能的 Vite 插件

## 目标与用户讨论

采用用户提出的新来源布局：移除src/skills和src/mcp分区，将coding、frontend、workflow、eval提升src一级；mcp-build-smoke归入eval。用户明确“就是一个eval集合，后面如果想新增集合，直接新建一个目录就好了”，因此发现逻辑不得维护固定集合名单；集合配置缺省也必须可以复制。

用户澄清只合并speckit-hooks.json，SKILL.md frontmatter保持原样；发布包名属于尚未决定的流水线部分；MCP内容暂不实现。关于hooks消费，用户回答“特定的脚本我们额外处理”，因此通用插件只复制集合配置，不生成逐技能配置或改写挂载行为。原始讨论见[集合方案](../requirements/discussions/2026-11-11-collection-build.md)。这是用户方向及后续澄清的实施方案，复用已有认可，不再重复要求相同范围批准。

使用writing-plans整理并在本会话按executing-plans/TDD执行；原Task身份和历史验收保留，新工作使用未占用的T072。只有tasks维护工程checkbox，不恢复已归档T067，不预填其他Task方案。

## 本轮具体结构

- 唯一构建配置：packages/skills/vite.config.ts。
- 一个插件：packages/skills/build/plugins/collections.ts；负责发现、校验、复制集合并创建空mcp目录，不引入旧来源快照、依赖图或发布模型。
- 每个已有集合增加collection.config.json。暂用packageName=null表示发布含义待定，mcp=false表示尚未选择MCP集合，hooks按技能目录名保存其完整原JSON。缺配置的新增集合使用同样默认值，不回写来源、不要求代码登记。
- 产物为dist/<集合名>/，包括完整技能与附件、集合同名配置；另有空dist/mcp/。本轮不生成MCP manifest、Release/安装投影、各集合package.json或dist/script，不假称最终安装/发布树已经交付。
- 采用Vite内部虚拟入口驱动构建，插件只提交内容资产并去掉内部入口chunk，产物不得包含占位JS。空目录在实际写出阶段建立；write=false不得写盘。

## 迁移与消费者范围

迁移前保存原文件字节及8份hooks配置；目录原样移动，逐技能hooks删除前确认其完整JSON已进入集合配置。技能正文、frontmatter、普通/二进制附件不改写；保护正在发生的另一功能线修改，按移动前实际字节核对。

通用本地消费同步link-skills默认src根、双平台脚本/测试/说明及estimate-context来源路径。hooks注册等专用脚本按用户边界后续单独适配，本轮不偷偷生成兼容附件或沿用旧路径宣称集成通过。原T065固定旧目录/阶段接口的测试保留历史语境，不通过削弱断言冒充新插件验证；本轮新增独立真实Vite集合测试作为当前契约。

## 实施顺序与验收

1. 保存、立即ESLint并读回方案，任务引用；同步新需求的有效范围。
2. 先用真实Vite临时工程建立失败用例：任意集合自动发现、无配置默认、完整正文/二进制、空MCP、集合配置逐字保留、来源删除后重建、稳定重建、非法配置/链接/保留目录名/危险输出在清理前拒绝、write=false零写入。运行取得真实失败后再写插件。
3. 迁移来源及配置，逐项核对原字节/配置对象，不调用全局安装或原生挂载。
4. 实现单插件及唯一配置，保持入口/资产路径安全，验证真实三方Vite结果而非只调用内部校验器。
5. 运行目标包lint/check-types/build/test、新集合测试及link-skills沙箱测试；共享包消费核对实际dist与源文件，记录缺PowerShell等环境项。专用挂载/安装/平台/发布未验分别说明。
6. 一次独立只读审查聚焦源/输出安全、自动发现、配置完整及测试误通过风险；修正后复验，不重复派审。
7. 保存analysis/acceptance/collections.md并按真实结果勾选T072。原T067只保留历史完成事实；T068等原接口/目录假设不能据本轮局部通过自动放行。

## 风险与门禁

无新增依赖（C1不命中），本轮无外部网络/挂载（C2不命中）；集合配置及Vite资产复制属于新契约和未经实证路径（C3/C4）。先用上述真实Vite测试保留骨架验证，失败阻止依赖该假设的复制和消费者，不以旧构建绿灯代替。

安全边界包括：源目录/文件不得通过链接逃逸；集合名mcp保留给输出；配置字段类型和hooks技能归属非法时在清理前失败；输出只允许位于本次包根的独立生成目录，不能覆盖来源/脚本/构建/用户目录；复制只处理内容，不导入或执行技能/脚本。测试拥有自己的临时目录，不修改真实dist以制造反例。

原发布、完整安装、真实挂载、MCP消费、GitHub Actions及迁后验收仍由后续明确范围承担。新集合测试通过只证明本轮输出，不解除完整发布门禁。
