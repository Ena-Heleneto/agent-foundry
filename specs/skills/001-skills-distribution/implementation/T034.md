# T034 依据本次成功名单写入隐匿规则

2026-11-19 用户要求按安装成功项写入隐匿。现有模板输出独立 Bash，使用安装入口已有的 Node 读取临时 JSON 数组。每项带 `name`、`installRelativeDirectory`、`installedPath` 和 `complete`，同时核对构建候选和明确的项目级安装路径。[curl 协议 1](../contracts/curl-delivery.md#隐匿内部调用协议1)

在 Git 索引确认目标未被跟踪后，为本次合格路径写入锚定的 `.git/info/exclude` 规则，保留原字节并去重。提示无适用本地仓库的情况，报告每个处理、跳过或失败的路径。Git 效果和退出码由独立测试验证。[T033](T033.md)

## 验证结果

目标包 Vite 构建通过。生成的安装入口与源码原字节一致，入口、隐匿、挂载三个产物通过 `bash -n`。在自有临时仓库实际运行 `dist/script/hidden-install.sh`，两个构建候选目录都存在，传入名单只含 `document-changed-symbols`。`git check-ignore` 只对名单中的技能返回 0，结果文件的已处理路径一致。
