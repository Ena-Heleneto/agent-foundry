沿现有 `--hidden` 开关，复制成功后记录安装目标，复用私有下载目录写名单和结果。运行同一解压包内协议 1 的隐藏脚本，读回它的独立结果。复制遇到第一个错误时保留原错误和已完成项，已完成项仍可交给隐匿。隐匿失败保留技能，安装全部成功时继续已有可选挂载，并在退出时反映隐匿失败。

用隔离归档验证实际复制和 Git 规则。该局部接线基于当前入口的 MD5 核验及复制方式，正式归档、SHA、选择与复用沿原任务验收。
