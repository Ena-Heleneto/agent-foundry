## 按需取得完整公开技能

外部用户希望选一个技能时只取得它与必要附件，选分类或整包时也不夹带未公开材料。正式选择范围仍为coding/frontend/workflow；eval评估源码可存在于开源项目，本地profile集合也不能因启用就自动成为获准发布内容。无选择、互斥选择、未知名称、缺依赖都须明确拒绝或要求补选，不能默认为全量。

技术上，现有vite-plugin-skill调用scanSkills读取TS集合配置，再复制启用正文与附件到dist/skill/<集合>/<技能>，不在插件中归档。默认构建已核对 11 项已启用技能的正文和附件字节。跨集合同名现在会在清理前报错，隔离验证已核对两个来源和旧产物字节。见 [T076 局部验证](../../implementation/T076.md)。其余复制验收沿 [T076](../../tasks.md#t076)。正式范围、非执行curl/skills.tsv映射与流水线统一归档由[T069](../../tasks.md#t069)形成，[T012](../../tasks.md#t012)核对完整来源及四种选择，原T010/T011只保留旧模型/路径证据，不能重开为新协议完成事实。

此功能以原MVU-001/008衔接：先得到完整可检查内容，再让下载安装器消费。独立可观察里程碑是正文/普通及二进制附件与流水线核验的正式来源完全一致、未选新增为零。已有[内容导出实验](../acceptance/content-export.md)及[旧集合证据](../acceptance/plugin-skill-config.md)只支持其当时输入；本轮重跑结果及未通过边界见[本地构建闭环](../../mvu.md#mvu-008按集合检查技能内容并自动接纳新增集合)。业务入口见[用户流程](flows.md)，实际构建及安装映射沿[技术图](../../diagrams.md)和[依赖图](../../diagrams/logic-flow.md)阅读。

## 安全下载安装与失败续接

使用者得到的不只是命令退出码，还要知道哪些技能真正完整安装、哪些失败或未执行。下载、依赖和包核验在本次私有临时目录中进行；正式提交的暂存须与目标同文件系统。未知同名、不同版本、用户修改或已跟踪目标拒绝覆盖，部分成功不能把残缺目录记为已安装。

当前 `install.source.sh` 已有基础版本表、MD5 校验、项目级复制和同包引擎调用。下载根仍是占位，临时依赖、整包校验、安装选择与完整阶段报告按各任务继续核对。[T016](../../tasks.md#t016)先验证HTTPS/摘要/接口及恶意成员反例，[T017](../../tasks.md#t017)接获取核验，[T018](../../tasks.md#t018)处理逐技能提交与成功集合，[T019](../../tasks.md#t019)保留选择/平台目标，[T020](../../tasks.md#t020)报告实际阶段，[T021](../../tasks.md#t021)留真实消费和恢复证据。T070在实际安装之后复核，不再让T012反向等待消费者。

统一包下载、长度/SHA、成员安全或根VERSION失败时零技能提交、零辅助执行。只有包已可信且所选技能完整时，同包hidden模块缺件/协议/执行失败才保留安装，报告“安装成功、隐匿失败”、overall=partial且非零；技能部分成功仍保留逐项失败，不能改报安装成功。原MVU-002的局部里程碑是完整可用技能及可操作重试说明；原三平台/动态agent/global、最低运行时和真实R2分别需要证据，局部Linux结果不能替它们通过。操作与样本矩阵见[验证指南](../../quickstart.md)，依赖转接见[流转图](flows.md)。

正式安装从最新 `install.sh` 启动，核验并复制后按需直接调用同版 `engine/install.sh`。T019 核对 Windows 取得入口及适用平台接线，未实证组合列为未验。T069的TSV与获准目录双向对应，不执行包内TS；T018在暂存时写入最小.foundry-source来源标记，清理后新进程重试同时核对来源标记与可信包正文附件全集，缺标记、不同版/来源、额外用户文件保持冲突。新数据、标记及反例已落到原任务，不代表源码已有实现。

## 同包辅助脚本与可选精确隐匿
