# PR 描述：技能发布、选择安装与工作流挂载

## 变更概述与解决的问题

让没有 Foundry 开发环境的用户，也能按需要获取完整技能及引用材料，并在适用的项目中接入已有工作流程。交付提供官方 skills 命令与下载脚本两条路径，覆盖整包、分类、单技能及多技能选择，避免用户为少量技能安装整个工作区。

## 澄清后的重点变化与交付要点

1. **先在当前仓库实现，再迁移公开。** 功能先在当前仓库实现并验证；之后由用户创建公开仓库，迁移技能及必要的发布、安装、挂载材料。地址在建仓后提供，外部使用不依赖原工作区，当前仓库无须转为公开。
2. **首版公开三个分类。** coding、frontend、workflow 纳入公开集合；eval 评估样本排除，仍保留当前仓库既有用途。整包及分类列出、安装都以公开集合为准。
3. **官方安装和本包脚本分别承担兼容责任。** 官方入口沿用上游平台、agent 和安装范围适配。本包自行维护的下载安装器与公共挂载脚本支持 Linux/macOS Bash 和 Windows PowerShell，分别验证。
4. **agent 范围与固定版本对齐。** 下载安装器覆盖选定版本 skills 的 agent 及安装位置约定；公共挂载覆盖其中 Spec Kit 原生支持的集成。计划阶段固定两种工具的版本和清单，不把上游未来新增能力自动列为已经支持。
5. **支持项目级及全局安装。** 下载安装器默认项目级，全局必须显式选择；目标 agent 不支持全局时在写入前报错。全局技能挂载必须指定目标项目，缺少项目时保留安装结果并明确报告挂载失败；关闭挂载时无需项目参数。

既定入口分工保持：下载脚本本次成功范围包含 workflow 时默认调用公共挂载入口，可用本包关闭开关跳过；官方技能安装后由用户显式执行第二步。入口核验本次版本、技能及实际位置后，先处理阶段动作，再注册指令，不连带处理未选择的技能或历史安装。

隐匿仍为下载安装器的可选能力，默认关闭。只排除适用项目内本次内容的精确路径；没有适用仓库时提示跳过，不向父目录寻找仓库。项目外的全局技能文件不属于该项目的排除范围，共享配置也不能因包含本包条目就整文件隐藏。

## 验证方法与操作途径

后续实施应在干净环境中，按承诺平台、agent 和安装位置分别验证四种技能选择方式，核对正文与必要附件完整、两入口内容一致、未选技能没有新增。全局不受支持时验证写入前拒绝。

挂载验收分别覆盖自动调用和显式第二步、单个模式、历史技能、关闭开关、缺少环境、未知配置冲突，以及全局安装指定或缺少目标项目。连续执行两次不增加重复条目；部分失败报告已完成与未完成内容，并能核对现场后续接。

隐匿验收检查默认关闭、普通仓库开启、无仓库目录、父仓库子目录、全局文件位于项目外、规则不可写和已跟踪文件；不得误隐藏其他文件。工作区已有文本清单分发、复制挂载和原生扩展入口需要范围内回归。
