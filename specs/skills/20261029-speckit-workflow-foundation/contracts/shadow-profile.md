# 契约：影子画像的项目接入、记录和恢复

日期：2026-11-14。依据：[当前规格](../spec.md)、[研究](../research.md#r57影子画像先源码复制后安装2026-11-14)及[最新复制路线输入](../requirements/raw/2026-11-14-shadow-profile-copy-first.md)。本文定义设计约束；源码、复制和真实宿主执行进度沿[实际验收](../analysis/acceptance/shadow-profile.md)，契约存在不代表行为通过。

## 来源与近期使用入口

唯一维护正文规划为 `packages/skills/src/profile/shadow-profile/SKILL.md`，元数据名称为 `shadow-profile`，标题为“影子画像”。必要附件随同源目录复制；没有实际需要不建附件。当前不要求集合配置、dist、正式安装器或新运行脚本，主线完成后另接安装，不修改紧急版固定集合。

用既有 `scripts/dev/actions/link-skills/link-skills.sh`，精确选择 `packages/skills/src/profile`，生成目标项目 `.agents/skills/shadow-profile`。复制后比较整个技能目录及必要附件，不能只比 SKILL.md 名称；副本不手改。根 `pnpm skills:link` 不含此来源，不能据其成功宣称本技能已复制。

## 项目必调用接入

在获准启用的项目 AGENTS 中维护简短引用：指定 shadow-profile 的已复制正文，每轮完整读取并执行，包括普通问答、确认、纠正及无 Task 的讨论；指定资料根，保存故障仍正常回答并提示缺档。引用不复制完整记录规则，不改工作流宪章，不新增模式、指令路由或阶段事件。重启或新建会话后核对项目规则确已生效，不假定修改文件会热更新当前会话。

每轮接入与新结论分开：必须执行记录流程，但无新认识可以保持结论和画像不变。新会话/中断恢复读取当前画像，持续协作复用有效认识，画像或依据变化时重核，不每轮全量读历史。

“必调用”是明确的 Agent 执行要求，交付须有声明支持宿主的真实每轮证据。缺引用、被更具体规则覆盖、技能不可读或实际漏调用均不能称已交付；配置存在、description 匹配、首轮读正文和 Agent 自称已调用均不能替代实际轨迹与保存结果。本期不承诺后台捕获、程序级拦截或不可见历史读取。

验收观察者指负责验证的人工或独立 Agent，按项目短引用、实际加载/工具轨迹及保存结果判定未接入或漏调用，记录未生效范围和证据。业务 Agent 未加载唯一入口时，不要求它自行知道该入口缺失，也不把没有自诊断提示算作正常调用；这不是新增常驻检测组件。接入已加载、执行 Agent 已知正文应被读取时，技能不可读由该 Agent 在正常答复中报告。两种异常分别验收，不以观察者发现故障冒充业务 Agent 已自动检测。

## 项目资料与使用者

先沿目标项目治理和已有有效资料定位同一资料根。当前项目沿 `.specify/memory/user-shadow/`；普通项目无约定时推荐 `docs/user-shadow/`，本地位置写在接入短引用中，不硬编码到通用正文，也不为此创建 Spec Kit。发现多个相互冲突根时先报告并澄清归属，不自动合并或迁移；记录受限不阻断原授权内正常答复。

根内保留 `conversations/` 日期摘要、`conclusions/` 日期结论及 `profile.md` 当前理解。现有有效文件及 Rnn/Enn 锚点优先续接；尚无认识时只建立真实摘要和说明理解不足的画像入口，首次有效结论出现后再建对应结论材料。

当前研发只有使用者本人，每项目仅维护本人的画像；他人发言只作必要上下文并标明来源，不混入本人偏好或另建他人画像。本人多个会话不等于多人支持；多使用者作为后续版本方向，不是本期前置，也不是永久排除。

对话摘要、结论和画像默认可纳入项目 Git，接入说明保留“暂行方案、后续可调整”。不得默认忽略三类资料，不由留档自动 git add、commit、push 或公开。个人资料不放入技能正文、附件、复制源或将来的分发物，不从原仓库复制私人画像，不写入凭据和环境变量值。

## 单轮内容和身份

输入仅限当前可见对话、已发生的工具行为、目标项目约定与实际已有画像。摘要保存意图、关键表达/决定、理由、实际结果、纠正、必要上下文、来源和覆盖限制；记录工具目的及关键结果，避免逐字复制全部输出，不记录隐式思维过程。

优先使用宿主实际提供且可见的会话与轮次 ID；不可得时，以明确标为本地的会话定位与本轮已保存 Rnn 锚点建立引用，不伪造宿主 ID 或精确时间。本地定位与轮次关系直接表达在摘要中，不另建注册表或状态文件。重复调用查找本轮既有记录，只补新发生内容；两轮同样的“好”或“继续”仍是不同轮次。无法唯一确认是否同轮时保留缺口并报告，不擅自合并来源。

正常保存发生在最终答复前，只覆盖已发生内容；真正最终答复可在下一轮仍可见时补记，不提前写计划中的答复或工具结果。建立了文件只能证明保存，真实调用与有效理解应用另验。

## 结论、纠正与当前画像

有效结论链接一个或多个摘要，说明情境、明确表达或暂定观察、确定程度与限制；普通进度、一次业务选择或 Agent 示例不直接成为永久个人特征。影响整体理解的有效结论才汇入 profile，并保留结论来源；无新认识不强改时间或重复生成结论。

纠正先保存真实表达，再关联旧结论和新的有效理解；旧来源不删除，profile 展示当前有效认识并链接更正依据。不同情境允许并存；无法确认哪项仍适用时保留冲突和待核实范围，不按文件更新时间自动定胜负。用户明确当前要求、项目事实、授权和验证证据优先于画像推测。

同一资料根的写入按摘要→必要结论→必要画像顺序串行，写前重读，保留外部已发生变更，局部合并而非用旧内存整份覆盖。没有原子事务或锁，不承诺任意并发无损；发现并行冲突保留现场、暂缓受影响画像汇总，正常答复继续，恢复后重核真实来源。

## 故障、恢复与效果

未接入或漏调用由验收观察者据实际证据报告；接入已加载后的技能不可读、摘要未写、结论未写或画像未更新，由执行 Agent 说明故障、实际已保存内容、影响及恢复入口。保存失败不阻断本轮正常答复和原授权协作，但必须提示故障及缺档，不能宣称完整留档或从旧画像倒推原话。

恢复读取真实文件及仍可核实来源，只补未完成部分，不重复建档，不回退已成功保存的前序资料，不声称多文件已原子回滚。不可见部分明确保留缺档；没有可用写入位置时在本轮真实答复说明，后续只能在该上下文仍可核实时补记，不承诺永久自动补齐。

在真实后续提问、取舍或纠正机会轻量核对是否应用当前理解，不逐轮报告/评分。读取成功或用户同意试用不算效果通过；没有适用机会明确未验。验收执行见[TV-13](../quickstart.md#tv-13影子画像源码复制与每轮行为)，不复用旧 T060/T061 冒充本新增能力通过。
