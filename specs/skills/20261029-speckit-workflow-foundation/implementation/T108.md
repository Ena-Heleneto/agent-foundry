## 实现与理由

在 `packages/skills/src/影子画像/shadow-profile/SKILL.md` 建立最小正文，名称 `shadow-profile`、标题“影子画像”。正文要求每轮完整读取，在最终答复前保存真实可见摘要；首次无认识时建立说明理解不足的画像入口，不强造结论。数据留在目标项目指定根，不进入技能源码。当前先验证最小执行假设，完整纠正、重复及失败恢复在后续原 Task 沿同一来源补足。

先在自有临时普通项目运行无技能对照，观察普通问题是否自然保存摘要。随后用既有 `scripts/dev/actions/link-skills/link-skills.sh` 仅选择影子画像源码分类复制到另一个临时项目，写最小 AGENTS 引用并启动新 Codex 会话。三个连续自然输入不点技能名，覆盖普通问题、人工测试偏好和简短确认；不将测试偏好记成本人的真实偏好。保留同一来源和案例用于后续增量。

使用本机实际 Codex CLI 与可观察 JSONL 工具事件；记录真实版本，不冒充桌面宿主。写入测试日志及隔离项目只在临时目录。仓库中的证据保留实际输入、命令、目录比较、读取/保存/答复的事件顺序与结果，必要原始轨迹脱敏后作为验收附件。不给业务 Agent 暗示预期答案，不伪造成功事件或用户反馈。
