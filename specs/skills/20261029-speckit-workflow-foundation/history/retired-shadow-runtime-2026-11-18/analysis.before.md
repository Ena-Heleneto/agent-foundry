## 画像帮助理解协作方式

### 完整对话原文与最后一轮

研发使用者能够回查完整可见原话，再随新对话重新提炼；记录包含用户与Agent文本、过程说明及普通实际最终回复，保留真实角色/顺序/来源，排除工具参数/原始返回、思维及系统开发者提示。新原文在项目资料根的conversations/raw按真实thread隔离，旧日期摘要和Rnn保留有限性质，附件只保存引用与说明，不复制原件。

主代理侧事件进程自动记录，消息完成后尽快追加、刷新并读回，成功后才计入已存和持久去重；同文本不同身份保留，同事件重投一份。主代理会话关闭则记录进程停止，不安排关闭后补录；每轮final不等于会话关闭，普通final在CLI继续运行时核对事件保存，不能等下一轮或预写；主动退出中断只记实际覆盖，不等退出收尾。[T114](../../tasks.md#t114)先验证真实来源/CLI运行时普通final的新消息事件和记录骨架，[T115](../../tasks.md#t115)沿通过骨架完善原文/过滤/恢复，失败保留覆盖和缺口。

维护正文仍为 `packages/skills/src/profile/shadow-profile/SKILL.md`；计划运行附件是同Skill的 `scripts/shadow_runtime.py`，宿主约束说明为 `references/host-contract.md`。当前源码尚是旧摘要能力，新附件未创建；[研究R65～R70](../../research.md#2026-11-16-五项澄清后的研究结论)及[契约](../../contracts/shadow-profile.md)已明确设计，不再把位置未定当政策缺口。已有[5条自动保存探针](../acceptance/shadow-auto-record-probe-2026-11-16.md)仅证明其样本，不证明普通最终回复、完整生命周期或正式持续接入通过；独立结束信号不再是额外前置，先验证新对话事件记录。

### 独立分析与有覆盖说明的精简入口

主代理在原有协作中识别新明确偏好、持续目标、用户纠正或手动分析要求，核验原文已存后实际派发分析子代理；普通消息先积累，不逐条另起分类模型，也不让子代理轮询。触发只是分析机会，结论仍需区分明确表达、Agent建议、观察、决定和适用情境，不将一次选择固化为永久特征。[T116](../../tasks.md#t116)承接增量及历史回查、来源链、更正及精简消费，至少覆盖真实正反触发与主代理继续任务。

子代理锁外分析已存来源，返回增量认识及snapshot依据；详细分析沿conclusions日期文件，coverage保留分线程已存/已分析/已发布的真实事实与缺口，profile为默认入口。正文最多2000字，详细依据按需读取，移出结束进度/重复/失效内容，长期偏好不按固定天数失效；原文和详细分析不因预算被截断。普通更正保留旧依据，遗忘另走删除协议。当前[模型](../../data-model.md#2026-11-16-完整原文与独立分析模型)明确字段关系和计数方式，已定政策不再重复提问。

分析尽快异步、不设固定时限，正常协作不等待，当前纠正在入口未更新时也立即应用。正常进展按需查询；已检测故障在当前会话下一次可见反馈说明缺口和恢复办法。可恢复分析失败按真实触发绑定的一轮最多自动重试1次；派发前在coverage持久预留并读回，重启/子代理重建/快照更新不重置额度，派发结果不明保留缺口而不盲目追加，细节沿[分析轮次模型](../../data-model.md#分析轮次重试计数与中断恢复)。仍失败停止本轮，待新正常触发或用户新的手动要求基于已存有效覆盖续接；分析已成功而入口失败只恢复缺失发布，不重复结论。原文保存、分析正确、入口可用和真实应用分别判断，真实应用无机会保持未验，旧T112职责保持。

### 多会话恢复、遗忘与最终来源

FR-033约束工程任务管理，不以程序锁或第二状态系统管理工程推进；本设计的文件锁仅协调运行期画像资料。多个会话更新同一入口时，全部正式writer通过资料根固定锁的短临界区；模型不持锁，子代理增量不能用整份旧稿覆盖新入口。发布必须同时检查快照后新增用户表达/纠正和遗忘代际，不能只重读旧profile。无冲突自动合并，明确更正依真实表达/来源/情境优先；不明冲突保留双方依据待核实，其他独立认识仍可合入。[T117](../../tasks.md#t117)用两个会话交错、旧分析晚到及真实锁/恢复边界验证，不以旧串行样本冒认并发无损或多文件事务。

遗忘先持久保存不含遗忘正文的失效代际/source_refs拒收，再删除三层相关内容、临时派生片段并修复引用；核对完成后才报告成功。删除中断则保留拒收和未完成范围，reader每次使用缓存或磁盘入口前检查代际/缺口，不消费受影响旧入口。旧分析/重试/恢复/原文重投迟到均不得重新写回相关内容，旧代际候选丢弃，不从旧备份回填；Git历史另议，验证只用隔离合成数据。具体机制已经设计，实际能力仍需原Task取得证据。

[T118](../../tasks.md#t118)在最终正文和必要附件完成后重新精确复制、实际加载并复验，不以候选通过替代最终入口消费；[T080](../../tasks.md#t080)继续唯一末尾，按真实用途处理过程产物，保护正式来源/历史证据/复用骨架，未知用途保留并记处理条件。普通清理不等于遗忘授权。

活动闭环详情沿[MVU-011](../../mvu.md#mvu-011)，实际职责/覆盖沿[tasks当前映射](../../tasks.md#2026-11-16-当前有效映射)，本页不复制状态或完成比例。[业务判断及里程碑](flows.md#2026-11-16-完整对话增量的业务判断)解释推进条件，[技术图](../../diagrams.md#2026-11-16-原文事件与主代理语义触发)解释运行职责，真实验证操作见[TV-14](../../quickstart.md#tv-14完整对话惰性分析与共同发布)。先前[上下文修复记录](../issues/2026-11-16-shadow-context-reconciliation.md)中的A1未答/U1设计缺口保留发生时语境，现已形成真实确认及设计输入，宿主验证仍未完成。

### 每轮记录与首次建档

以下保留旧摘要技能已交付范围及证据；其“答复前摘要/工具摘要”不能覆盖上方新的完整原文目标，旧结论、来源和工程完成事实不追溯改写。

研发使用者自然提问或确认，无须报技能名；项目短引用要求每轮执行影子画像，正常答复前保存已发生表达与工具摘要。没有画像时从可见来源开始建档，不导入旧私人资料；资料不足时只说明尚待形成理解。按[专项契约](../../contracts/shadow-profile.md)，[T108](../../tasks.md#t108)先以最小来源、精确复制和真实三轮证伪接入，[T109](../../tasks.md#t109)沿同一来源完善行为；漏调用不能用 description 匹配、文件存在或自述代替通过。现已交付源码及本仓库短引用/副本，有限宿主行为及真实首轮见[实际验收](../acceptance/shadow-profile.md)，不据此推定长期效果。

接入未加载或漏调用由验收观察者（负责验证的人工或独立 Agent）据实际轨迹及文件判定并记录，不能期待未加载唯一入口的业务 Agent 自行察觉，也不以其沉默判通过。已加载接入后的正文不可读或保存故障，由执行 Agent 在正常答复中提示；这一区分只明确验证职责，不新增检测程序，具体验收沿 [TV-13](../../quickstart.md#tv-13影子画像源码复制与每轮行为)。

### 结论、更正和缺档恢复

每轮摘要不等于每轮新特征：有效认识才提炼结论，影响整体理解才更新画像；不同轮相同话语保留不同来源，同轮重入只补新增事实，更正保留旧依据。新会话读取当前理解，来源/情境及本人归属沿[记录模型](../../data-model.md#2026-11-14-影子画像增量模型)核对，不能用偏好替代需求、授权或验证。保存失败正常答复并提示具体缺档，恢复仅补可核实内容；[T110](../../tasks.md#t110)验证最终来源及真实失败，[T112](../../tasks.md#t112)在后续真实机会核查理解应用，无机会保持未验，不以读取成功判效果。
