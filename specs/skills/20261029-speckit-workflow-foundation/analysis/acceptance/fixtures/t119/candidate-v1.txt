# 对话落盘

由用户与之交流的主 AI 执行本 Skill。启用后的每轮完整读取本正文，用当前可用文件工具保存新增可见发言并读回。保存、读回和缺口以真实工具结果判断，完成原授权问答及协作照常进行。

## 项目位置与启停

沿目标项目已有资料布局定位唯一资料根；无约定时使用 `docs/user-shadow/`。资料属于当前项目，不初始化 Spec Kit，不通过 AGENTS/CLAUDE 规则、后台进程或宿主日志调度，不复制其他项目私人资料。存在冲突位置时先说明归属，不自动合并。

在资料根同级的 `<根目录名>.recording-control.md` 保存最小控制事实；例如 `docs/user-shadow.recording-control.md`。已有等价位置时复用。首次启用时保存并读回项目相对资料根、启用决定的来源及可知日期；以后每轮先读取控制依据，再决定是否记录。控制说明只保留启停范围、来源定位、日期和当前有效决定，不复制发言正文或认识。

用户明确暂停或停止记录时立即遵守，只维护必要控制事实并读回；暂停期间不收集新原文。明确恢复后先保存读回恢复决定，再记录恢复请求及后续发言，不补暂停期。控制写入失败时当下已知暂停仍有效，说明持久化缺口；已知控制文件丢失、不可读或冲突时不推定恢复，核对仍可核验来源，不能确认则暂停受影响记录，正常协作继续。

删除、移走、清空或归档旧对话资料不解除已有启停决定，也不停止已启用的后续记录。控制说明保留，资料根缺失时沿原布局从清理后的新对话建立，不回填被清除内容。

## 保存原文并读回

读取当前可见对话和项目内已存范围，确定哪些发言尚未保存。原文默认使用 `conversations/raw/YYYY-MM-DD.md`，每条延续未占用且不复用的 `Mnn` 标题；已有等价布局直接沿用。保存完整正文、用户/助手角色、顺序、实际可知日期和来源关系。

宿主会话、轮次或消息 ID 实际可见时使用真实值；不可得时明确标注本地会话定位、轮次关系及文件锚点，不伪造宿主 ID 或精确时间。同轮重入只补缺，不同轮相同文字分别保留。无法确定是否同一消息时说明身份缺口，不按文字相同合并。

保存当前可见用户发言和已经发出的助手发言，包含过程说明及仍可核实的上一轮 final。正文用足够长的代码围栏原样包裹，保留空白、换行、Markdown、中文及 emoji，不改成摘要、不截断。工具调用参数及原始返回、思维、系统/开发者提示和控件封装不进入原文；非文本只记可核验引用及必要说明，不复制原件。

每次写前重读目标文件，只追加或局部补缺，再实际读回核对正文、角色、顺序及来源。写入成功不等于已读回。以文件和锚点说明确认范围、缺口及补存发生时点，不从摘要或画像倒推不可见原话。单写入者用例不得推定任意并发无损；遇共享写入冲突保留现场与未合入范围，继续正常协作。

本轮尚未发送的 final 不计已发生，不预写预期答复；下一轮仍可见时补存上一轮真实 final 并注明补存。无后续调用或内容已不可见时保留末轮缺口，不在退出后另起程序补录。结束当前轮次前，核对本轮已经出现且仍可见的新发言是否都已保存；报告覆盖时只依据已读回范围。

## 交付范围与故障

本 Skill 可独立使用，只保存原文及必要控制/覆盖事实，不要求摘要、分析或画像存在，不代写这些产物。向已启用的下游交付资料根、真实或明确本地来源、相对原文路径与锚点、实际读回范围和缺口；摘要及分析各按自身条件处理，未读回内容不交付。

获准保存且工具可用时实际尝试一次，以真实返回说明已写/未写部分，保存失败不冒称完整成功。保留已确认原文，在下一次可见反馈中说明故障与恢复入口，同时完成正常答复；恢复只补仍可核实缺项。所有资料留在目标项目，不进入技能来源，不自动提交、推送或公开。
