# 会话记录自动启动需求追加提示词

```text
请为 `specs/skills/002-conversation-to-skill` 起草一份需求追加草案，范围限于第一里程碑的会话记录。

安装即启用。用户按日常方式运行 `codex` 并发消息，无需手改配置、点名 Skill 或执行启动命令。每个符合记录条件的交互轮次都要自动进入记录流程，即使模型没有选用 Skill，也没有发起任何工具调用。

按现有规格拟定验收。用户原话须在业务动作前保存并读回，正常最终回复须在发出前逐字保存并读回。记录落在项目内且 Git 可见。覆盖空会话、首轮、后续轮次、模型零工具调用、非交互、合规恢复和 Git 提交停写。

现有需求规定仅安装记录 Skill，并由 AI 使用宿主已有工具执行。若候选方案需要随安装交付 Hook 配置或处理脚本，或需要用户首次确认 Hook 信任，请列出受影响的约束和待确认的决策。请给出 FR-002、SC-001 的拟修订条文，以及 T035 仍需补齐的实测证据，供评审确认。
```
