# T040 · 采用标题目录并续写原会话

2026-11-27，用户确认目录名称规则并同意在隔离项目实现和验收。以 T039 已核对的候选为输入，落点为同一日期目录下的会话目录和它包含的原话、详情及附件。 [用户认可](../requirements/raw/2026-11-27-recording-title-directory-name.md) · [标题候选验收](../analysis/recording-acceptance.md#t039-标题候选接收复验)

## 目录与变更

- 新会话按实际开启日保存 `records/<开启日>/<会话ID>/record.md`。详情位于该会话的 `details/<轮次ID>.md`，附件位于 `attachments/`。内部链接都相对所在文件，整个目录一起移动时链接仍能直接打开。旧布局的现有记录沿原位置续写。
- 安全回调取得 T039 候选后清理目录名。保留中文和空格，路径分隔符替换为短横线，空值及不可用名称使用会话 ID。按 UTF-8 字节预留后缀空间。资料根、开启日、会话与轮次身份沿原记录核验。主记录显示采纳的标题，恢复按真实 ID 找到唯一符合归属与名称规则的记录。
- 同一日期目录的同名组使用会话 ID 派生的短后缀，包括先取名的记录。名称冲突时延长后缀。改名和普通写入共享项目内的短时文件更新协调，并沿用会话锁。先核对目标占用、Git 索引和文件可见性，再移动整份会话目录并回读。若先取名的同名会话仍活跃，当前会话先采用短后缀，先取名的会话在后续安全回调补后缀。移动后未及保存显示标题时，仍可通过候选及实际目录恢复。提交及对应结果回复期间沿用停写规则。

## 验收

用已安装的四条 Hook 回归验证首条、采用候选、无可用候选、同名、目标冲突、恢复、中断后的续写、提交停写与旧记录。隔离 Codex CLI 复验用已核实的标题回包驱动正式目录更新，逐条打开主记录、详情和附件，跨日恢复仍得到同一份按原日归档的记录。对实际 `record.md` 和 `detail.md` 模板执行 ESLint 检查和修复。普通首轮自动派发、Codex 主动改名同步和 curl 安装属于后续安排。
