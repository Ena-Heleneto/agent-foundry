# T035 新版记录的隔离 CLI 复验

用户在 T034 收尾后回复「开始吧」，本轮从其本地实际构建产物安装到临时 Git 工作区，以合成数据执行 [记录验收](../quickstart.md#记录验收)。依据 [T034 交付核对](T034.md#交付核对) 逐文件比对安装结果，检查宿主发现与真实读取。按用例记录已通过、失败和未运行项，实际结果写入 [验收记录](../analysis/recording-acceptance.md)。当前工作区安装和真实仓库试用由 T033 完成。

先用普通问答验证主记录和最终回复时序，再用工具调用、同名附件与文件读回验证详情，随后覆盖恢复、Git 忽略、写入失败和实际提交边界。任何未通过的前置用例保留具体证据，继续能独立运行的对照。

## 2026-11-25 漏记修正复验

用户在讨论两项漏记的最小修正后回复「开始吧」。以[已复现的失败](../analysis/recording-acceptance.md#t035-漏记诊断)为基线。采集规则识别当前轮已展示的 `commentary` 原文并按真实顺序写入详情。触发说明显式覆盖「只回复指定文本」的短请求，记录工具在回复前执行，最终回复仍只发送指定文本。两个用例分别按实际宿主和文件证据判定。
