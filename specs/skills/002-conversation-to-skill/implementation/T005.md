# T005 对话内容来源验证

2026-11-23，用户在听取先做 T005 的隔离内容验证后回复「开始吧」。本轮复用 T002 样例、T004 的交互终端与隔离状态方式，核对模型在仓库内合成会话中实际可取得的内容。任务和采集要求见 [T005](../tasks.md) 与 [FR-005](../spec.md#functional-requirements)。

1. 准备有已知原文、顺序和哈希的短输出、长输出、分段输出及附件。让真实模型通过宿主命令和本地工具完成任务，核对调用名、完整参数、返回值、流式收取顺序和截断。用一个以仓库外样例目录为工作目录的调用验证它仍归于原宿主会话与轮次。
2. 在交互入口附加已知字节的合成图像，通过本地测试工具返回已知哈希的二进制附件及图像。比对本轮实际可见的内容、路径和附件原件。只有线索、转换版本或截断时记录实际范围。
3. 在独立父会话中调用宿主已有的子代理工具，实测派发、一次交互和回传。保留父会话、父轮次和实际子线程定位，并核对父会话可取得的名称、参数、输出与顺序。子线程正文不纳入取证范围。
4. 保存实际范围、缺口及可回查证据至 `analysis/content-source.md`。试验输入及驱动限于临时目录，记录逻辑和最终入口分别沿 T008/T010 与 T014 承接。
