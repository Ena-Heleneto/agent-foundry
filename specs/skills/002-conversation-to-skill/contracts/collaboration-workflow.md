# 契约 · 记录、提炼、分析与协作 Skill

## 记录入口

首期记录工作目录位于本仓库根目录或子目录、由用户开启的交互式 Codex CLI 会话。通过宿主支持的仓库级配置及信任流程启用，以开启时的有效工作目录和交互入口证据核定源会话，再按宿主提供的稳定身份建档。恢复同时核对原会话的归属和本次交互入口的有效工作目录，后者取宿主切换到历史目录前的来源。工具事件按已核定的会话归属关联，其工作目录用于详情回查。

| 输入                                                 | 可观察产物                                             |
| ---------------------------------------------------- | ------------------------------------------------------ |
| 已验证的会话开启、用户发言、工具活动、回复及关闭信号 | 按日期保存成对记录，索引直接定位对应详情和实际改动文件 |
| 可取得的完整工具参数与输出、原始附件                 | 对应详情块及本地附件原件                               |
| 中断、写入失败、恢复与历史补读                       | 已验证的原文件接续、缺口标记及可核实的补记             |

正常发言先落盘再执行对应会话工作。保存失败先标记缺口并继续任务。运行中遇到上游内容缺失时写明实际可得范围。具体来源随宿主版本取证。 [技术调研](../research.md)

## 父代理及子代理

| 流程 Skill | 入口条件及输入                                                     | 阶段产物                                                   |
| ---------- | ------------------------------------------------------------------ | ---------------------------------------------------------- |
| 记录       | 用户开启会话后自动启用，处理实时事件和按会话补读的材料             | 记录由接入端保存，提供索引、详情、附件和缺口供其他阶段读取 |
| 提炼       | 本仓库已确认保存的对话足以支持用户特点，提供可定位的对话与来源目录 | 每项一份特点文档，含情境、证据解释和原始块定位             |
| 分析       | 提炼文档足以形成或修订规则，提供有依据的特点和当前有效的规则范围   | 一份协作 Skill 的规则与依赖资源，以及留存在本地的依据关联  |

记录入口向父代理提供已确认材料的可用线索。父代理分别判定两个阶段，已确认的特点可以在后续会话中直接成为分析输入。首次自动提炼以新流程保存并确认落盘的本仓库记录为输入，旧影子画像对话作为历史资料保留。

每次派发交接要关联父会话、轮次、实际子线程、阶段及范围内的证据定位。分析还记录派发时的规则版本。子代理回传候选产物和所用依据，父代理读回并核对来源、确认状态及当前版本后再采纳。派发失败或回传未确认时继续使用当前有效产物。 [数据模型](../data-model.md)

## 协作 Skill 的消费和维护

最终目录依照 Agent Skills 规范交付，可按兼容代理常规方式加载。正文使用适合跨项目协作的规则及适用情境，所需资源通过目录内相对路径定位。消费端仅凭交付目录即可应用，原始对话和依据在本地回查。 [Agent Skills 规范](https://agentskills.io/specification#file-references)

用户删除本地当前的一条规则时，同步清理独占提炼依据及失效关联，共享依据继续服务其他规则。旧分析返回时依据当前删除决定处理，后续有效的新一轮可按原始材料重新形成规则。
