| 观测场景 | 判定及定位 |
| --- | --- |
| 仓库根、仓库内子目录首次交互 | 两个线程分别满足建档条件 |
| 仓库内恢复仓库内线程 | 按原线程、归属和开启日续接原索引和详情 |

| 仓库外恢复仓库内线程 | 跳过，本次启动目录在仓库外 |

| 用例 | 观察到的判断 |
| --- | --- |
