## GitHub Spec Kit

两个技能功能规格中的历史验收归档，以及packages/skills/tests/fixtures/specify/.specify中的官方脚本、核心模板与安装渲染内容，来源于[GitHub Spec Kit v1.2.6](https://github.com/github/spec-kit/tree/v1.2.6)。这些上游内容及其派生片段继续保留MIT，完整正文见[SPEC-KIT-MIT.txt](SPEC-KIT-MIT.txt)，不由本仓库ISC替换。夹具overrides中的自有增补采用ISC；foundry-dev夹具只保留历史初始化行为，不是新根安装入口。

公开派生归档随附同一MIT正文及_PUBLIC_DERIVATION.json来源映射。机器路径、私人记录引用和两份私人核查材料的处置见根migration-manifest.json及各归档派生清单；原摘要只代表发生时的输入，不构成新仓库的工程、发布或使用验收。
